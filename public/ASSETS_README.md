# Add these files to `public/` (optional but recommended)

- **resume.pdf** – Your resume PDF. The site links to `/resume.pdf` (Header + Contact).  
  Without it, "Download Resume" will 404 until you add this file.

- **og.png** – Social sharing image (1200×630 px). Used when the site is shared on Twitter, LinkedIn, etc.  
  Without it, shares may show no image or a fallback.

- **projects/ndisync.png** – NDISync (ndisync.ai) landing/screenshot. Put it in `public/projects/`. Recommended: 800×450 px. The card links to https://ndisync.ai/
- **projects/shifara.png** – Shifara QA project screenshot. Put it in `public/projects/`. Recommended: 800×450 px.
- **projects/recciaga.png** – RecCiaga QA project screenshot. Put it in `public/projects/`. Recommended: 800×450 px.

`favicon.svg` is already included.
