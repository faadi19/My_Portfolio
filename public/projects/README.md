# Project screenshots

Place your project images in this folder with these exact names (lowercase):

| File name        | Project   | Live URL             |
|------------------|-----------|----------------------|
| **ndisync.png**  | NDISync   | https://ndisync.ai/  |
| **shifara.png**  | Shifara   | https://shifara.com/ |
| **recciaga.png** | RecCiaga  | https://recciaga.com/ |

- Recommended size: 800×450 px (or similar landscape).
- If a file is missing, the card will show a fallback (first letter) until you add it.
- Paths used in the app: `/projects/ndisync.png`, `/projects/shifara.png`, `/projects/recciaga.png`.
- NDISync card links to **https://ndisync.ai/** (Live →).
